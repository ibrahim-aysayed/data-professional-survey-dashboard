# Data Professional Survey Breakdown | Power BI

## Project Overview
An interactive Power BI dashboard built to analyze survey responses from data professionals, exploring their career paths, salaries, technical preferences, and overall job satisfaction.

## Dashboard Features
- **Survey Demographics:** Analyze survey participants by country and average age.
- **Salary Analysis:** Compare average salaries across different data-related job titles.
- **Programming Language Preferences:** Explore the most popular programming languages among data professionals.
- **Career Entry Challenges:** Understand how respondents perceive the difficulty of entering the data industry.
- **Job Satisfaction:** Analyze satisfaction levels regarding salary and work-life balance.
- **Interactive Filtering:** Explore survey results across different geographical groups.

## Tools & Technologies
- Microsoft Power BI
- Power Query
- DAX
- Data Visualization


## Project Objective
To explore trends in the data industry by transforming survey responses into meaningful visual insights about salaries, career preferences, and professional satisfaction.
